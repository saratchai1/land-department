# LAND Intelligence

เว็บเดโม่ภาษาไทย **6 โครงการยกระดับกรมที่ดินสู่ Intelligent Land Administration** สำหรับทดลองกระบวนการและนำเสนอผู้บริหาร

> ข้อมูลทั้งหมดเป็นข้อมูลสังเคราะห์สำหรับสาธิต ไม่ใช่เว็บไซต์ทางการ ไม่เชื่อม API ของกรมที่ดิน ไม่มีข้อมูลประชาชนจริง และไม่มีผลต่อทะเบียนสิทธิ

## สิ่งที่ทดลองได้

| โมดูล | การทดลอง |
|---|---|
| Command Center | เลือกสำนักงานจำลอง ปรับกำลังคน ดูกราฟคิว 20 วันทำการ และกิจกรรมจากโมดูลอื่น |
| Smart Registration | ตรวจฟิลด์เอกสารตัวอย่าง แก้รหัสผู้โอน/พื้นที่/เอกสารแนบ ดูไฮไลต์ และบันทึกผลทบทวนโดยเจ้าหน้าที่ |
| Intelligent Survey QA | ตรวจพื้นที่ วงรอบ เส้นขอบตัดกัน และพื้นที่ซ้อนทับที่คำนวณจากพิกัดตัวอย่าง |
| 3D Cadastre | เปิด–ปิดชั้นสิทธิ หมุนมุมมอง แยกชั้น เลือกปริมาตร ดูแปลน และดาวน์โหลด SVG |
| Smart Survey 2.0 | ปรับ 2–4 ทีม เปลี่ยนงานเร่งด่วน ดูตารางงานและเปรียบเทียบแผนที่คำนวณได้ |
| Anomaly Review | กรองคะแนน/สถานะ ดูสัญญาณและเส้นเวลา บันทึกผลสอบทานพร้อมเหตุผล |

มีคู่มือสาธิต 4 นาทีในเว็บ ปุ่มรีเซ็ต และการส่งออก JSON กราฟและแบบจำลองเป็น SVG ในแอป ไม่พึ่งภาพหรือแผนที่ภายนอก

## เริ่มใช้งาน

ต้องมี Node.js 22 ขึ้นไป ไม่มี runtime dependency และไม่ต้องใช้ API key

```sh
npm run dev
```

เปิด URL ที่แสดงใน terminal (โดยปกติ `http://localhost:5173`) รองรับ `PORT` หรือ `--port`

```sh
npm test
npm run check
npm run build
```

ผล build อยู่ใน `dist/` นำไปใช้กับ static hosting ได้ โดยใช้ `index.html` เป็น entry point และ hash routing ภายในหน้า จึงไม่ต้องกำหนด SPA rewrite

## การจำลองที่ใช้

- Registration เปรียบเทียบฟิลด์ตัวอย่างที่สกัดไว้แล้ว **ไม่มี OCR/LLM จริง**
- Survey QA ใช้ shoelace area, convex polygon clipping และการตรวจวงรอบ/เส้นตัดกัน ใช้กับพิกัดสังเคราะห์แบบจำกัด ไม่ใช่เครื่องมือรับรองแนวเขต
- 3D เป็นภาพประกอบปริมาตรเชิงพื้นที่ ไม่ใช่การสร้างหรือรับรองสิทธิทางกฎหมาย
- Scheduling ใช้ heuristic ที่อธิบายได้ เปรียบเทียบกับ round-robin บนชุดงานเดียวกัน ไม่รับรองว่าเป็นคำตอบดีที่สุด
- Anomaly flags เป็นสถานการณ์ที่กำหนดไว้ล่วงหน้า คะแนนคือผลรวมของน้ำหนักที่เปิดเผย ไม่ใช่ความน่าจะเป็นของการทุจริต
- Queue forecast ใช้สมมติฐานอัตรารับเข้า/กำลังรองรับคงที่ ไม่ใช่พยากรณ์จากข้อมูลกรมที่ดิน
- สถานะบันทึกใน localStorage ของเบราว์เซอร์นั้นเท่านั้น ถ้าปิด storage แอปยังทดลองในหน่วยความจำได้ ข้อมูลไม่แชร์ข้ามเครื่อง
- ฟอนต์ออนไลน์เป็นส่วนเสริม หากโหลดไม่ได้จะใช้ฟอนต์ในเครื่อง
